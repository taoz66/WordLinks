# 词文库 / WordLinks 产品约定

本文记录当前面向用户的产品行为与数据边界。新的会话要求可以更新这些约定，改动时请同步更新本文。

## 产品目标与核心术语

词文库是原生 macOS 英语阅读与词语积累工具：用户在本地导入或撰写文章、连续阅读、划词保存语境释义，再从词条或文章回看原句与原文。基础阅读、词形预填与手动积累完全离线可用，不依赖 AI 或联网。

| 名称 | 含义 |
| --- | --- |
| 个人档案 | 独立的阅读资料、文件夹、阅读位置与积累记录（与 AI 服务配置独立）。 |
| 文章文件夹 | 当前档案中的单层文章分类；删除文件夹会将其中文章放回根目录。 |
| 原始划选 | 用户在正文中选中的原文文字与范围。 |
| 积累写法 / expression | 用户为该次积累确认的英文表达，可与原始划选不同。 |
| 积累卡片 | 一次原文位置上的积累，包含表达、非空释义、原始划选及保存时完整例句。 |
| 词条 | 按规范化表达聚合的一组积累卡片（折叠空白、忽略大小写、统一 `...` 为 `…`）。 |
| 释义项 | 同一词条下按完全相同释义文本聚合的一组积累，不自动合并近义释义。 |
| 内置词形索引 | 随包携带的只读英文词形索引，用于保守预填原型，不是用户个人词库。 |
| 精读 | AI 逐句翻译与悬停短语对应模式。 |
| 专注阅读 | 隐藏侧栏与文章列表的阅读模式（`⇧⌘F`），与「专注」排版样式及精读相互独立。 |

## 文章、文件夹与个人档案

- **添加文章入口**：搜索框旁提供固定宽度的 `+` 图标菜单，包含「新建文章…」「从文件导入…」「模板」。
  - 新建文章仅提供编辑表单（不设预览切换），标题与正文必填，作者、日期、来源、原文链接为可选；表单自动识别正文中的 Markdown 结构并保留普通文本分行。
  - 模板页只展示与当前界面语言对应的一份中/英文模板，支持复制到剪贴板并提示「已复制 / Copied」；模板中的 `Author/Date/Source:` 或 `作者/日期/来源：` 及 `(optional)`/`（选填）` 提示按规则解析或剥离，中文 `##正文小标题` 可直接识别为小标题。
- **文件导入与同步**：支持 `.md`、`.markdown`、`.txt`（UTF-8 或带 BOM 的 UTF-16）。支持简单 YAML 头；批量导入逐篇反馈成功或失败。默认保存独立托管副本；选择「与原文件同步」时关联外部文件为事实来源，文件变更后自动同步标题、正文、位置与可重定位标记。
- **数据安全**：文件改写导致原始划选不再存在时，保留积累写法、释义与历史例句（转为脱离原文记录），隐藏失效高亮。每个档案原子写入，保留最近十份自动备份；支持档案切换、JSON 导入导出（导入解除外部文件绝对路径绑定）及单篇 Markdown 导出。读取损坏资料时明确报错，不用空白覆盖原文件。

## 阅读界面、工具栏与专注模式

- **三栏结构与标题规则**：
  - 第一栏（侧栏）：阅读库（全部文章、文件夹、新建文件夹）、积累（词条、文章）及底部个人档案菜单（前导对齐）。
  - 第二栏（内容列）：展示搜索框、列表（文章列表单行尾部省略并支持悬停看全文），**顶部不显示任何标题**。
  - 第三栏（详情栏）：**仅在阅读文章时**，于详情栏顶部工具栏区域单行显示当前文章标题（左起对齐在详情栏边界内、右侧工具栏按钮之前，超长尾部省略并保留完整全文悬停提示）；未选中文章、处于词条/文章积累页或进入专注阅读时不显示该标题。
- **工具栏与菜单**：
  - 侧栏开关（`sidebar.left`）位于前导导航区；「显示」菜单同步提供显示/隐藏边栏、专注阅读（`⇧⌘F`）、精读、显示释义/例句命令，并在不可用时禁用对应项。
  - 精读与专注阅读共用功能组，设置按钮独立成组。工具栏固定仅图标显示，禁用标题栏/工具栏空白处右键显示模式切换菜单；仅精读按钮在右键或 `Control+单击` 时弹出「重新生成」菜单。
- **正文阅读与排版**：
  - 支持 Markdown 标题、粗体、斜体、列表、引用、行内代码、链接与显式换行；纯文本保留原文换行与标点；作者、日期、来源显示在正文标题下方，不破坏原文字符索引。不支持的复杂嵌入元素保留可读文字并提示，不自动联网抓取。
  - `⌘F` 页内查找，`⌘G` / `⇧⌘G` 上下跳转，`Esc` 关闭查找；选中文字支持系统词典及系统翻译（macOS 14.4+）。
  - 四种样式（标准、书页、专注、杂志）适配浅深色，正文居中且最大宽度 820 pt；各样式独立记住字号、行距（默认 8 pt）、段间距与边距，「恢复默认」仅重置当前样式。
  - 应用支持中文（默认）与英文切换，4 套应用图标颜色切换后立即更新 Dock 图标。
- **专注阅读**：
  - 隐藏侧栏与内容列，最小窗口宽度由 980 pt 降至 420 pt，保留窗口尺寸与全屏状态；工具栏仅保留精读与专注按钮，随鼠标/键盘活动与原生窗口红黄绿按钮共同显现，空闲约 3 秒后共同隐藏（悬停控件区、菜单/弹出框/Sheet、焦点、拖动缩放或开启 VoiceOver 时保持显示），且显隐不引起正文跳动。
  - `Esc`（有查找栏时先关查找）、`⇧⌘F` 或菜单可退出并恢复进入前的两栏或三栏布局。

## 卡片、词条与积累视图

- **划词建卡**：划词后在选区附近弹出原生卡片编辑器并聚焦释义框；点击外部保留草稿，保存、取消或删除后清除草稿。点击已有高亮可编辑或删除，重叠选区不重复建卡。
- **保守词形预填**：仅对内置词形索引中有直接、唯一依据的小写英文单词预填原型（如 `books → book`、`walked → walk`）；歧义词、首字母大写、短语与未知词保持原始划选。不修改旧卡片或用户编辑。
- **积累浏览**：
  - 「词条」按最新词条在前展示同一表达下的各释义项、历史例句（加粗原始划选）、日期与来源文章；「文章」按文章回看并按原文顺序展示卡片，点击卡片可跳转完整词条。「查看原文」以纯文字链接回跳至卡片所属文章的准确位置（脱离原文的卡片不伪造跳转）。
  - 「显示选项」可分别隐藏释义与例句，两视图共享并记住选择；隐藏释义同时隐藏词条列表摘要。

## 积累内联编辑与六列 CSV 导出

- **内联编辑**：仅双击实际文字区域进入原生文本编辑（首次全选）；词条视图仅可编辑释义（以编辑开始时固定的同释义组卡片 ID 批量保存），文章视图可分别编辑词条或释义（仅当前卡片）。失焦自动提交，空白或无变化不写入；`Esc` 先取消会话再失焦。保存失败保留草稿并在底部控制栏提供重试/放弃；成功写入支持窗口系统 `⌘Z` 撤销/重做（按原档案与记录 ID 还原，不改动原文位置与历史例句）。
- **六列 CSV 导出**：
  - 积累页工具栏提供导出菜单（支持导出整个词条库、当前词条、当前文章关联词条；空词库时禁用），活动积累窗口 `⌘E` 固定导出当前档案整库。
  - 导出前先结束当前窗口内联编辑并固定一致快照（按 `createdAt` 升序、卡片 UUID 升序）。
  - 编码固定为带 UTF-8 BOM、CRLF 换行、全字段英文双引号包围（内部引号双写），六列表头为：`词条, 释义, 例句, 文章标题, 文章路径, 日期` / `Entry, Definition, Example Sentence, Article Title, Article Path, Date`（日期按用户时区公历 `yyyy-MM-dd`）。
  - 通过原生保存面板确认路径，重名时预建议最小可用 `(1)`、`(2)` 编号，写入成功后轻量提示「已导出 N 条积累」并自动消失。

## AI 服务与功能约定

- **服务管理**：支持 ChatGPT、自定义 API（统一承载远程与本机 Chat Completions 兼容端点，有密钥即 Bearer 认证、留空无认证）与 Apple 智能（macOS 26+ 端侧系统模型）。
- **测试与激活**：三类服务共用简洁测试反馈（测试中加载图标 / 绿点「服务可用」 / 红点「服务不可用」）。自定义 API 与 Apple 智能须显式测试通过后才可点击保存激活；ChatGPT 登录账号后首次短测或已有账号显式测试成功即激活，不设保存按钮。未激活或迟到的测试结果不改变当前生效服务；仅拉取模型列表或仅完成 OAuth 授权不足以激活。
- **模型选择**：自定义 API 使用单个原生模型菜单，显式触发「获取模型列表」或「手动输入模型 ID」并显示原始模型 ID；编辑地址或密钥会清空列表缓存。
- **功能边界**：
  - **询问 AI**：短词/短语返回语境释义，完整句/长选区走翻译模式；释义模式回覆就绪后可在弹出框右上角一键划记保存为卡片（若已有完全相同卡片则显示确认态，重叠选区保留禁用提示）。
  - **AI 预填释义**：默认开启，候选建议与手填分离，用户未输入时保存可采用候选，手工输入后不被迟到建议覆盖；额度错误后暂停后台预填直到显式重试或测试通过。
  - **精读**：按文章分批生成逐句译文与短语对应并按档案、文章、语言缓存；每篇文章独立持有开关与生成进度，切换文章或专注阅读不中断后台生成。随包内置权威离线精读资源（`intensive-reading.json`），未配置 AI 或离线时阅读内置材料亦可秒开逐句译文与双向短语高亮对应；用户若使用个人激活的 AI 重新生成，则保存至当前档案并优先覆盖内置结果。

## 内置资源

内置 50 篇开放许可阅读材料，分属三个文件夹：5 篇 Global Voices（CC BY 3.0）、30 篇 Wikipedia（CC BY-SA 4.0）与 15 篇 PLOS（CC BY 4.0），均保留作者、日期、来源链接与尾部许可说明，并移除图表、参考文献与行内角标夹注以适合连续阅读。按集合标识对每个档案仅投放一次，删除后不自动恢复，已知未编辑旧副本支持增量更新并保留用户资料与 UUID；同时支持自动加载本地资料目录下 `LocalCollections/*/catalog.json` 中的个人私有集合（如迁移后的个人真题），确保公开开源仓库与用户私有资料严格分离。第三方语言数据库与文章许可各自独立保留。
