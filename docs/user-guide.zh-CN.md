# WordLinks（词文库）使用指南

WordLinks（词文库）是一款原生 macOS 英语连续阅读与语境词汇积累工具。你可以在本地导入或撰写文章、连续阅读、划词保存语境释义与原句，并随时开启离线或 AI 驱动的逐句精读模式。

## 核心概念

| 术语 | 说明 |
| --- | --- |
| **个人档案** | 独立的阅读资料库，包含各自的文章、文件夹、阅读进度与积累卡片（与 AI 服务配置相互独立）。 |
| **文件夹** | 当前档案内的单层文章分类；删除文件夹会将其中文章移回根目录，不会删除文章本身。 |
| **词条 / 积累写法** | 卡片上保存的规范化英文表达（可自动还原为词根原型，也可以手动编辑）。 |
| **积累卡片** | 锚定在原文位置的一条积累记录，包含表达、释义、原始划选与保存时的完整例句。 |
| **词条聚合** | 按规范化表达（忽略大小写、折叠空白）聚合的一组积累卡片，方便跨文章复习同一词条的多种语境。 |
| **精读模式** | 逐句呈现自然中文译文，并在鼠标悬停英文单词或中文短语时双向高亮对应的语义词组。 |
| **专注阅读** | 沉浸式阅读模式（`⇧⌘F`），收起侧栏与文章列表，并在静止阅读约 3 秒后自动隐藏窗口控制栏。 |

## 阅读库、导入与文件同步

- **添加文章**：点击搜索框旁的 `+` 菜单，可新建文章、导入 `.md` / `.markdown` / `.txt` 文件（支持 UTF-8 及 UTF-16），或查看内置文章模板。
- **外部文件同步**：导入时默认保存托管副本；勾选「与原文件同步」后，外部编辑器对原文件的修改会自动同步到阅读库中，同时尽量重定位并保留已有高亮标记。
- **数据安全与备份**：所有档案均采用原子写入，并在 `~/Library/Application Support/ReadingToolDaily/` 下自动保留最近 10 份备份；支持整库 JSON 导出与导入。

## 连续阅读与专注模式

- **四种阅读风格**：在 **设置 → 外观** 中提供 **标准、书页、专注、杂志** 四套主题样式，各样式独立记忆字号、行距、段距与左右边距。
- **页内查找与系统查词**：支持 `⌘F` 页内查找（`⌘G` / `⇧⌘G` 上下跳转，`Esc` 关闭）；选中文本后可使用 macOS 系统词典与系统翻译。
- **专注阅读（`⇧⌘F`）**：隐藏侧栏与文章列表，空闲约 3 秒后与窗口红黄绿按钮同步淡出，移动鼠标或按键即可唤回。

## 划词建卡与词汇导出

- **划词建卡**：在正文中选中单词或短语即可在选区附近弹出原生卡片编辑器。对于内置词形索引中的常见小写屈折词（如 `books → book`、`arriving → arrive`），会自动预填词根原型且不覆盖手动输入。
- **双视图复习与内联编辑**：支持按「词条」或按「文章」浏览积累，点击「查看原文」可精确回跳至原文位置；双击词条或释义即可直接内联编辑，并支持 `⌘Z` 撤销/重做。
- **六列 CSV 导出（`⌘E`）**：支持导出整个词条库、当前词条或当前文章关联词条，生成带 UTF-8 BOM 的标准 6 列 CSV 文件，兼容 Excel 与各类记忆卡片工具。

## AI 服务与精读

在 **设置 → AI** 中可按需配置以下服务（所有密钥与令牌均安全存储于 macOS 系统钥匙串）：

- **ChatGPT**：通过 OpenAI 官方开源 OAuth 授权登录直连。
- **自定义 API**：兼容任意 OpenAI Chat Completions 接口（包括远程服务及 Ollama、LM Studio、vLLM 等本地大模型，本地无认证端点可将密钥留空）。
- **Apple 智能**：在 macOS 26+ 上使用系统端侧模型，零网络请求。

### 开箱即用的离线精读

应用内置 50 篇开放许可精选文章（Global Voices、Wikipedia、PLOS），其中 33 篇核心文章随包附带经过严格校验的离线精读与短语对齐数据（`intensive-reading.json`），无需联网或配置 AI 即可秒开。如需使用自己的 AI 重新生成，可在工具栏「精读」按钮上右键或 `Control+单击` 选择「重新生成」。
