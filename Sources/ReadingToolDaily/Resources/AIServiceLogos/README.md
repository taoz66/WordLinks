# AI service logos

These first-party brand assets identify the AI services in WordLinks settings.
They are bundled locally; displaying them makes no network request.

Retrieved on 2026-11-11:

- `chatgpt-original.svg`: the official ChatGPT knot mark, downloaded unchanged from
  <https://chatgpt.com/cdn/assets/favicon.6a33781f61.svg>, as linked by
  <https://chatgpt.com/>.
- `chatgpt.pdf`: a vector PDF conversion of that original SVG using CairoSVG
  (`cairosvg.svg2pdf`). The original path geometry and transparent canvas are
  preserved. The app renders it as a native monochrome template in the current
  appearance's primary color, matching the source's light/dark intent.
- `apple-intelligence.png`: the unchanged 512 × 512 official Apple Intelligence
  icon, downloaded from
  <https://developer.apple.com/assets/elements/icons/apple-intelligence/apple-intelligence-256x256_2x.png>,
  as displayed on <https://developer.apple.com/apple-intelligence/>. The app keeps
  its original colors, proportions, and rounded background.
