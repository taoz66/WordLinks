# 应用随附的只读词形索引

本目录是应用随附的只读运行时数据，包含 `lexicon.sqlite3`、上游许可和修改/署名说明。应用使用系统 SQLite 查询词形关系，不联网，也不会写入这个索引。

完整许可和修改说明见 `NOTICES.md` 与 `LICENSES/`。索引已经随应用资源包分发，运行时不依赖项目外部目录或生成脚本。

SPECIALIST Lexicon 官方入口：https://lhncbc.nlm.nih.gov/LSG/Projects/lexicon/current/web/index.html
Open English WordNet 入口：https://en-word.net/

中文释义来自用户填写。详细条款见 `LICENSES/` 与 `NOTICES.md`。
